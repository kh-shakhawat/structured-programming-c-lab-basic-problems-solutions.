# C Programming Lab: Basic Problems

Solutions to 13 basic problems from the **Structured Programming Language**
course (Undergraduate, CSE) written in C. Topics covered: input/output with
`scanf()`/`printf()`, arithmetic operators, unit conversion, swapping, and
digit manipulation using the modulus operator.

## Problems
| File | Problem |
|------|---------|
| a_gross_salary.c | Gross salary from basic salary |
| b_distance.c | Convert km to meters, feet, inches, cm |
| ... | ... |

## How to Run
gcc a_gross_salary.c -o gross
./gross
